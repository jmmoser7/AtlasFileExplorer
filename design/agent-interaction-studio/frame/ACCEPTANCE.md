# Frame acceptance
Status: draft. Native pixel parity is UNVERIFIED.

1. Pin the current native source hashes, bundled font, fixture input, theme, camera, viewport, DPR and animation time. source-baseline.json identifies working-tree bytes normalized to LF. Do not refresh pins to hide drift.
2. Run node check-baseline.cjs and node --test geometry.test.cjs. No Rust build is needed for these gates.
3. Query native owners into JSON with schema slate-frame-native-candidate/v1, renderer rust, sourceManifestSha256 and cases [{id,metrics}]. Each ID and input is in fixtures.json; metrics must match FrameBaseline.metricReport and reference-metrics.json. Run node check-baseline.cjs --candidate path/to/native.json. A missing case/field, nonfinite number, wrong color, token, enum or order is NO-GO. World geometry tolerance is 0.0001 for these bounded fixtures; projected geometry scales that bound by zoom, normalized factors use 0.000001. These bounds address f32 arithmetic only.
4. Native reports must come from production Rust queries, not copied JavaScript expectations. Self-reported provenance is an audit aid, not proof of independent execution. Native journals separately prove one mutation per gesture, cancellation, persistence and command routing.
5. Only after numeric and interaction gates pass, capture native and browser at identical viewport/DPR, camera, theme, content, pointer and time, with the pinned font loaded. Include idle/hover/selected, rotated ±27/45/90/135/180/270, tiny hosts, overlap, authored fill/stroke/corners, palettes, tooltip/cursor and presentation states.
6. Preserve original PNGs and hashes. Report exact pixel-difference count and maximum/mean channel delta, plus regional diffs and overlays. Do not resize, blur, realign or widen thresholds to conceal discrepancies.
7. Independent screenshot reviewers must interrogate geometry, text, AA, colors/alpha, clipping, hover transitions, shadow absence, rotation and control placement until the UIs are indistinguishable. Missing native evidence or an unresolved visible/behavioral delta keeps acceptance pending.

Run check-properties.cjs as well as check-ui.cjs to exercise real property panels, duplication, shortcuts and multiple-slide controls. FrameStudio.metrics().interaction exposes the panel and menu measurements specified in PROPERTY_SPEC.md before a screenshot pass. Current browser captures, browser-report.json and property-report.json establish HTML behavior only. Gaps listed in the Frame contract remain required work. No native screenshot pair is currently included. No future Rust approval follows automatically from Studio review.
