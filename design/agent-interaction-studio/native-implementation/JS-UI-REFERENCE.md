### Reference interaction sequence

1. Select an ordinary source, open its existing Agent tool. Open the compact model trigger: main four-row popup, correctly aligned even when unsupported parameters say Automatic.
2. Click Provider: Provider header stays fixed; provider choices replace later root rows. Open API provider's **secondary** chevron, then Add/Change. Cancel returns without changing provider/draft/source. No paid call is needed to test this path.
3. Choose a provider, reopen Model, select a genuinely available model. Observe current check and complete accessible identity; repeat with the deliberately long fixture label. Reopen Effort/Speed; choose supported values; verify disabled fields and Standard zero bolts.
4. Click outside: popup closes and that click does not accidentally deselect/change the underlying source. Escape closes the popup before the Agent panel can consume a subsequent Escape. Open model/options repeatedly: one active popup, consistent owner and layer above selection chrome.

JS outside capture: `generator-ui.js:25–26`. Shared picker itself exposes close/open rather than owning every canvas Escape. Native two-Escape ordering is an owner/native integration requirement, with earlier actual proof limited to the recorded bound fixtures.

## Native source correction — 1 November 2026

Latest explicit owner steering takes precedence over prototype defaults: every individual Image, Text, Web/Dashboard and Model starts with its native simple content and output. Only opening that node's existing robot/Agent dialogue reveals its generator input configuration. Expansion is per node in the active workbook; it neither activates siblings nor turns authored text into a prompt. Closing the dialogue returns to simple resting chrome; only actual authored connected input slots remain inspectable, at their canonical positions; unused roles remain hidden and bindings are unchanged. Existing output/history data and canonical saved endpoints are retained. Native Text keeps its white text sheet, with no overlapping legacy Prompt/Run field; the approved expanded dialogue owns Send.

An output dropped onto empty canvas opens the existing modality chooser before creation, including Text, Image, Dashboard and 3D. Cancellation creates no node. Only the chosen modality creates its blank, closed downstream source, without a provider run; Preserve carries the appropriate immutable history snapshot. This explicitly replaces the prototype's automatic Image-only downstream creation.

An allowed Web source has no permanent Revoke site button. Its existing revocation and Website access commands remain in the Web context menu; blocked pages retain inline Allow site. Command authority and revocation effects are unchanged.
