# Icon concepts

Generated with the built-in image generator. Concept assets; not installed as application icons.

## File Atlas

Use case: logo-brand. Create one compelling minimal desktop app icon for File Atlas, a visual file organization app with folder trees and maps. Design a distinctive bold geometric folder silhouette with a beautifully integrated negative-space branching path / atlas-map motif. Extremely simple, memorable, balanced, legible at 24px; only 2 or 3 substantial shapes, generous negative space, no thin lines. Premium flat vector-like design, crisp edges, a restrained single accent color chosen to suit a calm creative productivity suite. Centered isolated mark, occupies 75% of a square canvas, genuinely transparent background. No text, no letters, no wordmark, no mockup, no border, no shadows, no 3D, no texture, no tiny files or decorative details. This is one of a coordinated File Atlas and Slate icon pair; both use the same visual language of bold folded planes and negative-space cuts.
