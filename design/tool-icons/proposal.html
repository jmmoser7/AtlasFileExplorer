Individual tools · A / B comparison

Recommendation: A / Quiet outline

Use A as the base: lighter visual weight, clear negative space, and less competition with the board. Keep its solid selection arrow. B offers stronger silhouettes for quick scanning, but filled object tools can become visually dominant.

What changes first

Select / Pan: recognizable arrow and continuous hand contour. Frame / Rectangle: extended frame rails versus a closed shape. Arc / Polyline / Bezier: smooth curvature versus angular vertices versus explicit control handles. Trim / Split / Join: removed side, separated pieces, joined endpoints. These metaphors need a short recognition review before adoption.

Proposed rules for future icons

    Review before implementation

    Compare at 20 px first, then 16 px. Toggle dark mode. Check whether neighboring tools remain distinguishable without labels. The state examples illustrate visual treatment only; changing click, hover, pin, or flyout behavior requires a separate interaction decision.
