   the subagent's first command must abort on a mismatch. Draft for

   ```text

   Abort if toplevel is the main checkout
   (C:/Users/jmoser/source/repos/AtlasFileExplorer) or the branch is not
   the one in this prompt. Do not write a file until both match.
   The parent moves the agent root onto the worktree before launch;
   subagents cannot move it themselves.
   ```

2. **Semantic search before grep.** `.cursor/rules/reading.mdc` is now
   always-on (905 characters, ~226 tokens) and this run followed it:
   no god file was read whole. The rule still lists grep and semantic
   search as peers. A `fn` grep in `tests.rs` returned 869 hits, and a
   comment scan wrote an 80 KB file. Semantic search should be the
   first hop; grep is for an exact symbol, scoped, with a head limit.
   Effort: one sentence in `reading.mdc`. Risk: low (an exact string
   can still be grepped second). Saving: agents stop pulling whole-file
   inventories into the turn. The rule does not yet shrink exploration
   by itself, because the unit of navigation is still the file.

4. **`cargo xtask map`.** A generated code map plus a symbol index.
   Effort: one xtask command and a freshness test, same shape as
   `size` (library function, `cargo xtask map`, assertion in
   `xtask/tests/`). Risk: medium. The snapshot churns on every public
   item, and it is large enough to hurt if an agent reads it whole.
   Saving: high once a scout or a parent queries one row instead of
   opening a 10k-line file. Not always-on context.

   Output, committed so the test can see it:

   - `docs/metrics/code-map.jsonl` — one object per `.rs` file under
     `crates/`, `apps/`, and `xtask/`, `target` excluded. Fields:
     `path`, `lines` (newline count, same as the size lint), `purpose`
     (first line of the inner `//!` doc comment, or empty), `owner`
     (crate or app directory), `items` (each `pub` / `pub(crate)`
     function, struct, enum, trait, type, const: `name`, `line`,
     `vis`, `doc` = first doc line).
   - `docs/metrics/symbols.tsv` — `name`, `path:line`, `vis`, one row
     per item, for the lookup.

   Freshness: `xtask/tests/map.rs` runs the collector and fails if the
   committed files differ. `cargo test --workspace` already runs xtask
   tests. `cargo xtask map` rewrites the files; the test never writes.

   Size, estimated from this tree: 347 `.rs` files, 280,016 lines.
   A column-0 item count (functions with or without `pub`, plus public
   types) is 5,644. The map emits only `pub` and `pub(crate)`, so the
   index is smaller than that, on the order of a few thousand rows.
   At about 90 bytes a row, `symbols.tsv` is roughly 0.3–0.5 MB,
   about 70k–120k tokens if pasted whole. A lookup is one row. File
   purposes add roughly 10k tokens for the whole catalog. Do not load
   either file into the prompt.
