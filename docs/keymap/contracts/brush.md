## Feel constants

- `SOFTNESS_STEP`: 0.25
- `SOFTNESS_DRAG_PX`: 100 screen px across the full 0–1 softness range
- `SIZE_DRAG_GAIN`: 2 screen px of diameter per px of horizontal travel
- Opacity range: 0–1 (brush opacity, eraser strength, curve opacity, smooth strength)
- `WHEEL_SLOT_RADIUS` / `WHEEL_HUE_OUTER` / `WHEEL_HUE_INNER` / `WHEEL_SV_RADIUS`: 130 / 112 / 92 / 84 screen px (`WHEEL_RING_GAP` 8)
- `WHEEL_SNAP_RADIUS`: 8 screen px around the white and black points
- `WHEEL_DOT_HIT`: 10 screen px
- Style row (`board_tip_hud`): icon radius 21, hit radius 24, spacing 50, row 36 px under the circle's rim; the band starts 8 px under the rim
- `ViewState::WHEEL_COLOR_LIMIT`: 24. Editors still show `RECENT_COLOR_LIMIT` (6)
- Existing `[` / `]` screen-px tiers and `draft.drag_threshold` (4 px)
- `SYNC_STAMP_PX`: 256 × 256 stamp pixels rasterized on the frame loop per frame; larger strokes build on the raster workers (D11)

## Textures

User, 27 September 2026: "brush texres are very heavy and load down the system. for each of the types avalable look closly at prior art from tools like photoshop."

A textured stroke is stamped as the plain tip first, with the same max coverage and dither as Smooth. Each finished pixel is then scaled once by a factor between 0 and 1. The factor comes from two inputs. One is the pixel's depth into the stroke: 0 at the rim, 1 at a quarter radius in or deeper. The other is paper fields baked once per process: 512² periodic value noise, tiling every 256 world units, sampled bilinearly in world coordinates. There is no noise evaluation per dab and nothing regenerates per frame. A dense stroke's overlap skips pixels that are already at full opacity and full depth. The rim factor is applied to the finished stroke, so a wet edge never rings the joints between segments. The grain never raises coverage above the plain tip. The board, its tiles, the live brush and eraser previews, and the HTML artifact all run the same `vector_ink` code, so they paint the same pixels (Art. IV).

| Texture | Prior art (Photoshop) | Model |
|---------|-----------------------|-------|
| Smooth | Default round brush | Factor 1. |
| Graphite | Graphite / sketch pencils: fine grain, slightly metallic mid-gray tooth | A fine tooth field lifts up to 30 % of the body in the paper's valleys, rising to 65 % at the edge. |
| Pencil | Hard pencil on rough paper | Harder, coarser tooth thresholded against depth: the edge breaks up into paper grain and the body is speckled. |
| Ink | Hard round ink / technical pen: pressure-free, uniform | Uniform 90 % density with a crisp edge and a slightly darker wet rim. |
| Watercolor | Wet-media watercolor brushes: wet edges, granulation | Translucent wash (40–56 % of the tip opacity) with blooms and pigment granulation, a darker wet edge on a rim that wanders with the paper. Separate strokes build by source-over. One stroke keeps D11's max coverage, so its own overlaps do not build. |

Cost (`cargo test -p vector-ink --test bench_grain -- --ignored --nocapture`, dev profile, 400-point wave, 48-unit tip, stamp at 0.5 world units per pixel, same machine, before → after in ms): Smooth 50 → 25, Graphite 95 → 46, Pencil 98 → 47, Ink 88 → 46, Watercolor 112 → 49. Setting `SLATE_GRAIN_SHEET=<dir>` writes a PNG swatch per texture for judging the look.

## Golden paths

- **GP1:** Shift+[ from hardness 0 reaches 25, 50, 75, 100 and stays there. Shift+] steps back by 25.
- **GP2:** Alt+right-drag +40 screen px horizontal and 50 px up, from a 10 px diameter and hardness 0, sets diameter 90 and softness 0.5, with the circle still centered on the press. Esc restores both.
- **GP5:** From softness 0.8, Alt+right-drag straight down into the style row reaches softness 0 at the band, sweeping sideways across the band changes neither size nor softness, and releasing on a swatch keeps softness 0 and that style.
- **GP3:** Recent colors fill clockwise from 6 o'clock, a repeat moves to slot 0, and the 25th new color drops the oldest. A second use of the same color is a single entry at 6 o'clock.
- **GP4:** A stroke painted at softness 0.5 stores that value. The HTML artifact embeds a PNG of that stamp and does not emit `feGaussianBlur` for it.

## Implementation notes

Softness and `Stroke::stamp` live on `Stroke`. A stamped stroke is drawn by `vector_ink::stamp_contours` on the board and embedded as a PNG by `slate-artifact`. Recent colors stay one list on `ViewState`: index 0 is 6 o'clock. The size HUD and color wheel are pointer-attached chrome, so their type stays in screen pixels.
