What counts as resolved?

A case passes only when every expected result passes in this run, the running build is confirmed, and an observation or evidence reference is recorded. One failed result fails the case. Untested, blocked and partial cases remain open.

A report is a closure candidate only when every linked case passes. For look, feel and user flow, your acceptance is required. A failed historical check is a reopen candidate even if an earlier test suite passed.
